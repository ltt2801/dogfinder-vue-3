# DogFinder - a web application for dog lovers

An intuitive, responsive web application designed to help users swipe through and discover their favorite dog breeds!

---

## 🛠️ Tech Stack & Technical Decisions

- **Framework:** [Vue 3](https://vuejs.org/) (Composition API + TypeScript) - Provides high performance, strict type safety, and maintainable codebase.
- **Build Tool:** [Vite](https://vitejs.dev/) - Official build tool for Vue 3 offering fast HMR (Hot Module Replacement) and optimized production builds.
- **UI & Styling:**
  - [PrimeVue v4](https://primevue.org/) - Selected for robust, accessible UI components.
  - [Tailwind CSS v4](https://tailwindcss.com/) - Integrated for rapid utility-first layout styling and responsive design.
- **State Management:** [Pinia](https://pinia.vuejs.org/) - Official Vue store for managing global state (like voting progress, persisted breed history, and last viewed items).
- **Routing:** [Vue Router 4](https://router.vuejs.org/) - Handles seamless navigation between Main Page, Details Page, and History Page.
- **Code Quality & Tooling:**
  - **ESLint & Prettier:** Maintains consistent code formatting and enforces standard coding style rules.
  - **Husky & lint-staged:** Configured pre-commit hooks to auto-fix and validate code before every commit.
